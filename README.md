# TuRutaIA — MVP

MVP mobile-first de TuRutaIA para planificar rutas turísticas personalizadas por el Perú.

## Funcionalidad

El MVP no utiliza una API de IA. La personalización se realiza mediante una matriz (`routes.json`) y reglas basadas en:

1. Lugar
2. Tiempo
3. Presupuesto
4. Intereses
